# EE posters

Posters for electrical engineering students, each in its own folder with its sources and build.

- [The Ten Commandments of Electrical Engineering](10-commandments/): ten ideas every EE student should leave university with,
  set out in King James English.
- [What if a is A?](linear-systems/): the lecture notes on analysis of linear systems on one A1 portrait poster.
- [Which screw drive?](screw-drives/): fourteen screw drives on one 16:9 slide, grouped by who can open them, and five joints that never come apart.

## Contributing

Pull requests and bug reports are welcome.
Please run `just check` before opening a pull request; a poster/slide/pptx with too much information kills the message, paraphrasing [Tufte, 2003].
